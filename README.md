# Vitrum Game Profiler — Releases

Installers and automatic updates for **Vitrum Game Profiler**, the performance testing tool used by the Vitrum Games team.

Installed copies of the app check this repository and update themselves. To install for the first time, download the latest `VitrumGameProfiler-Setup-x.y.z.exe` from [Releases](https://github.com/Icepun/game-profiler-releases/releases/latest).

This repository only hosts release builds; it contains no source code.
